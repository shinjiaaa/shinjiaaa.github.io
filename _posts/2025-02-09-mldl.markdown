## Overfitting(과적합)이란?

모델이 학습 데이터만 과하게 학습하여 새로운 데이터(test)에서는 일반화 성능이 떨어지는 현상을 의미합니다.  
쉽게 말하면 **모델이 학습 데이터셋을 외운 상태**라고 볼 수 있습니다.

- 학습 시(train) 높은 정확도 & 낮은 loss
- 테스트 시(test) 낮은 정확도 & 높은 loss

과적합은 주로 **Epoch을 필요 이상으로 많이 학습**할 때 발생합니다.  
학습 데이터셋을 과도하게 학습하면서 **데이터의 노이즈와 패턴까지 암기**하게 되는 것이죠.

---

## 과적합 시 확인 포인트

- train과 validation(val) loss가 갑자기 벌어지는 지점 확인
- val은 test 수행 전에 모델 성능을 미리 평가하는 용도

> 가장 고성능의 Epoch 값은 **train과 val loss가 과하게 벌어지기 시작하는 시점**에서 얻을 수 있습니다.

---

## 해결 방법

요즘은 모델이 과적합 상태에 빠지지 않도록 **Early Stopping**과 **Model Checkpoint**를 사용하여 자동으로 제어할 수 있습니다.

- 학습 중 train과 val loss 격차가 커지기 시작하면 학습을 자동으로 중단(Early Stopping)
- 그 시점의 모델 가중치를 **best.pt**로 저장(Model Checkpoint)
- best.pt는 **val loss가 최소가 되는 시점의 모델**로, train과 val의 균형이 가장 잘 맞는 모델입니다.

---

## Python 예제 코드 (YOLOv8)

```python
from ultralytics import YOLO

# 모델 불러오기
model = YOLO('yolov8n.pt')

# 학습 설정 및 수행
results = model.train(
    data='dataset.yaml',   # dataset 설정 파일
    epochs=100,            # 최대 학습 Epoch
    patience=3,            # Early Stopping: 성능 개선 없으면 3 Epoch 후 중단
    batch=16,              # 배치 크기
    imgsz=640,             # 이미지 사이즈
    project='runs/train',  # 결과 저장 폴더
    name='exp',            # 실험 이름
    exist_ok=True          # 폴더 덮어쓰기 허용
)
```
